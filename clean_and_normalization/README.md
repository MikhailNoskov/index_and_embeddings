# 📄 Пайплайн обработки и дедупликации документов

Этот скрипт реализует конвейер (pipeline) для автоматической загрузки, очистки, нормализации и удаления дубликатов из технической документации в форматах **PDF** и **Markdown**.

## 🔍 Что делает пайплайн?

1. **Загружает** все файлы с расширениями `.pdf` и `.md` из папки `./docs` (рекурсивно).
2. **Очищает** текст:
   - Удаляет строки вида `Company Confidential 2024. Все права защищены.`
   - Убирает разделы вроде `...Содержание...`
   - Приводит пробелы и переносы строк к единому формату.
3. **Нормализует** текст — приводит всё к нижнему регистру.
4. **Добавляет метаданные**: длину очищенного текста (`content_len`).
5. **Удаляет дубликаты**, используя векторные эмбеддинги:
   - Для каждого документа генерируется embedding через модель `all-MiniLM-L6-v2`.
   - Если косинусное сходство с уже обработанным документом превышает заданный порог — документ отбрасывается.
   - Документы короче 200 символов пропускаются (считаются незначимыми).
6. **Выводит** на экран краткую информацию об оставшихся уникальных документах.

---

## 📥 Входные данные

- **Директория**: `./docs/` (должна находиться в той же папке, что и скрипт).
- **Форматы файлов**:
  - `.pdf` — обрабатываются через `PyMuPDFLoader`
  - `.md` — обрабатываются через `UnstructuredMarkdownLoader`


> ⚠️ Скрипт ищет файлы по шаблонам `**/*.pdf` и `**/*.md` — то есть рекурсивно во всех подкаталогах `data/`.

---

## 📤 Выходные данные

Скрипт **не сохраняет файлы**, а только выводит в консоль краткую информацию о каждом уникальном документе:

```text
Первые 50 символов очищенного текста...
Источник: docs/руководство.pdf 1245 

Ещё один уникальный фрагмент текста...
Источник: docs/заметки.md 872 
```

## ▶️ Запуск
### С порогом по умолчанию (0.95)
```
python process_docs.py
```
### С кастомным порогом дедупликации
```
python process_docs.py --threshold 0.90
```
Допустимые значения --threshold: от 0.0 до 1.0.
